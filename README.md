# كلامي نص — تحويل الكلام والريكورد لكتابة

تطبيق ويب مجاني بيحوّل كلامك أو أي ريكورد/ملف صوتي لنص عربي مكتوب، بسرعة ومن غير تسجيل ولا سيرفر.

## التشغيل

افتح `index.html` في متصفح كروم، أو استخدم النسخة المنشورة على GitHub Pages.

## المميزات

- **كلام مباشر**: دوس الميكروفون واتكلم، النص يظهر لحظيًا (Web Speech API، لغة `ar-EG`).
- **رفع ملف صوتي**: MP3 / M4A / WAV وأي صيغة تانية — التحويل بيحصل بالكامل على جهازك باستخدام Whisper (transformers.js)؛ الملف لا يغادر جهازك أبدًا، وبعد أول تحميل للنموذج يشتغل حتى بدون إنترنت.
- نسخ / مشاركة / تحميل النص كملف، وعدّاد كلمات وحروف.
- واجهة عربية RTL، شغالة على الموبايل والكمبيوتر.

## ملاحظات

- الكلام المباشر يحتاج إنترنت ومتصفح يدعم Web Speech API (كروم أفضل اختيار).
- أول استخدام لتحويل الملفات يحمّل نموذج (~60MB للوضع السريع) ويُخزَّن في الكاش للاستخدامات التالية.
